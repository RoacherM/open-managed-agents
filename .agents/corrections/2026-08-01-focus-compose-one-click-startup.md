# 先聚焦 Compose 的一键可用启动契约
- 日期 / agent：2026-08-01 / codex
- 我原来的理解：需要从整个自托管运行时分析 Environment、Model Card、Skill、Sandbox、Vault 等所有缺口。
- 用户实际要的：先聚焦 `docker-compose`，目标是一次启动后得到可直接使用的 Open Managed Agents 平台，并区分缺失项究竟是用户配置还是启动封装缺陷。
